# JVL.PLATFORM — Volexturn v4.0.0

`index.html` یک کلاینت تک‌فایلهٔ فارسی/راست‌به‌چپ به نام **Volexturn** است که برای
**شبکهٔ محلی** ساخته شده: چت دونفره و گروهی، استوری، پست/اکسپلور، ویس‌چت زنده و
معرفی سرورهای بازی. این مخزن بک‌اند آن را تأمین می‌کند — در **دو حالت**:

| حالت | بک‌اند | کجا اجرا می‌شود | ذخیره‌سازی |
|---|---|---|---|
| **MQTT** (پیش‌فرض) | هیچ! لایهٔ MQTT داخل مرورگر | **GitHub Pages**، هر هاست استاتیک | پیام‌های retained بروکر |
| **سرور نود** | Express + Socket.IO + SQLite | هر دستگاه با نود ۲۲ (PC، سرور، Termux) | دیتابیس + فایل روی دیسک |

`index.html` خودش تشخیص می‌دهد کدام را استفاده کند: اگر سرور نودی پشت همان آدرس
باشد به آن وصل می‌شود، وگرنه حالت MQTT را بالا می‌آورد. **یک فایل، دو حالت.**

```
حالت MQTT:   مرورگر ←→ MQTT/WebSocket ←→ بروکر عمومی/خصوصی     (بدون سرور)
حالت نود:    مرورگر ←→ HTTP + Socket.IO ←→ Express ←→ SQLite + دیسک
```

## ۱) اجرا روی GitHub Pages (حالت MQTT)

Pages این مخزن روی شاخهٔ جاری و مسیر `/` فعال است، پس **push کردن = دیپلوی**:

```bash
git push origin arena/ac24cb6b-jvl-platform
# →  https://javadxpro.github.io/JVL.PLATFORM/
```

چون همهٔ مسیرهای `index.html` نسبی است و دارایی‌ها (`static/js`، `static/fonts`)
داخل مخزن commit شده‌اند، هیچ سروری لازم نیست. جزئیات کامل، نقشهٔ تاپیک‌ها و
محدودیت‌ها: **[docs/MQTT.md](docs/MQTT.md)**.

## ۲) اجرای محلی (هر دو حالت)

نیاز به **Node.js ۲۲.۵+** (برای `node:sqlite`):

```bash
npm install
npm start          # سرور نود روی http://localhost:3000  → حالت REST
npx http-server .  # یا هر سرور استاتیک دیگر            → حالت MQTT
npm test           # ۱۱۱ تست
npm run doctor     # سلامت نصب + همگامی نسخهٔ صفحه با سرور
```

اولین کسی که ثبت‌نام کند **مدیر** می‌شود.

## بن‌کردن کاربر و نشانی

بن از دو لایه تشکیل شده، چون بستن حساب تنها کافی نیست: کاربر می‌تواند حساب
دوم بسازد.

| لایه | چه می‌کند |
|---|---|
| **بنِ حساب** | توکنِ فعلی همان لحظه بازمی‌ماند (۴۰۳)، نه در ورود بعدی. اتصال زندهٔ Socket.IO هم با رویداد `banned` قطع می‌شود و نشست پاک می‌شود. |
| **بنِ نشانی** | IP آخرین نشست بسته می‌شود. همهٔ مسیرها — از جمله `/login` و `/register` — با ۴۰۳ رد می‌شوند، پس ساخت حساب دوم از همان نشانی ممکن نیست. |

**نکتهٔ امنیتی:** در حالت پیش‌فرض `X-Forwarded-For` **نادیده گرفته می‌شود**، وگرنه
کاربر بن‌شده با یک هدر جعلی از بن رد می‌شد. اگر پشت ریورس‌پروکسی هستی،
`JVL_TRUST_PROXY=1` را بگذار تا IP واقعی از اولین هاپ خوانده شود.

ورودی می‌تواند تک‌نشانی (`91.98.7.211`) یا محدودهٔ CIDR (`91.98.7.0/24`) باشد —
IPv4، از `/8` تا `/32`. بنِ `127.0.0.1` و `::1` رد می‌شود تا در را روی خودت نبندی.

آخرین IP هر کاربر در `users.last_ip` نگه داشته می‌شود (در ورود و در هر درخواست
احراز‌شده)، چون برای بن‌کردن به همان نشانی‌ای نیاز داری که کاربر واقعاً با آن آمده.

**در حالت MQTT/Pages بنِ نشانی ممکن نیست** — هیچ سروری بین مرورگر و بروکر عمومی
نیست، پس IP کسی دیده نمی‌شود. در آن حالت فقط بنِ حساب انجام می‌شود و رابط هم
صادقانه همین را می‌گوید (`ip_error`).

## حالت MQTT در یک نگاه

| چیز | چطور |
|---|---|
| state (کاربر، پست، گروه، لایک…) | پیام **retained** → کاربر تازه هم فوراً همه را می‌گیرد |
| رویداد (پیام، تایپینگ، سیگنال ویس) | پیام **غیر retained** روی `…/evt/*` |
| حضور آنلاین/آفلاین | **retained + Last Will** — با بسته‌شدن مرورگر، خودِ بروکر آفلاین می‌زند |
| حذف | انتشار **payload خالی** روی همان تاپیک |
| رسانه | `data:` URL — عکس فشرده در یک پیام، ویدیو/فایل بزرگ تکه‌تکه در چت |

تغییر بروکر و کلید شبکه از کنسول مرورگر:

```js
JVL.setBroker('wss://broker.hivemq.com:8884/mqtt');
JVL.setNetworkKey('khdodemon');
JVL.mode();     // 'mqtt' یا 'rest'
```

> ⚠️ روی بروکر عمومی **امنیت واقعی وجود ندارد** (هر کسی می‌تواند تاپیک‌ها را
> بخواند) و **تاریخچهٔ چت با رفرش از بین می‌رود**. برای استفادهٔ جدی، بروکر خصوصی
> با ACL یا همان حالت سرور نود را استفاده کن. جزئیات: [docs/MQTT.md](docs/MQTT.md).

## دستورهای CLI (حالت نود)

```bash
node server/cli.js start [--port 3000] [--host 0.0.0.0]
node server/cli.js create-admin <username> [password]
node server/cli.js create-user <username> [password]
node server/cli.js promote <username> | demote <username>
node server/cli.js list-users
node server/cli.js stats [--json]
node server/cli.js doctor
node server/cli.js reset --yes
```

| متغیر محیطی | پیش‌فرض | توضیح |
|---|---|---|
| `PORT` / `HOST` | `3000` / `0.0.0.0` | پورت و آدرس سرور نود |
| `JVL_DATA_DIR` | `./data` | دیتابیس، کلید امضا و آپلودها |
| `JVL_DB` | `./data/jvl.db` | مسیر دیتابیس |
| `JVL_SECRET` | خودکار | کلید امضای توکن |
| `JVL_QUIET` | — | با `1` لاگ درخواست‌ها خاموش می‌شود |

سقف حجم در حالت نود (`server/config.js`) همان `LIMITS` کلاینت است: عکس ۵MB،
ویدیو ۱۰MB، فایل ۵۰MB. در حالت MQTT رسانه به `data:` URL تبدیل می‌شود: عکس تا
~۷۰۰KB فشرده می‌شود و در یک پیام می‌رود؛ ویدیو و فایل بزرگ‌تر **فقط در چت** به
تکه‌های ۱۲۰KB بریده و تا ۱۰MB فرستاده می‌شوند (غیر retained، یعنی موقتی).
جزئیات: [docs/MQTT.md](docs/MQTT.md).

## نکته‌ها

- **میکروفون** فقط در `localhost` یا HTTPS کار می‌کند؛ روی Pages که HTTPS است
  مشکلی نیست، ولی از `http://<IP>` روی LAN نه.
- **همگامی نسخه**: `APP_VERSION` در `index.html` باید با `Config.app_version`
  یکی باشد؛ `cli doctor` و `tests/cli.test.js` همین را چک می‌کنند.
- **زمان**: مهرهای زمانی به قالب محلی `YYYY-MM-DD HH:MM:SS` هستند، چون کلاینت
  با `new Date(ts.replace(' ', 'T'))` می‌خواندشان.
